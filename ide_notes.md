# Git в VS Code и терминале

## Три удобные возможности VS Code
1. Source Control собирает изменённые файлы в одном списке и позволяет подготовить отдельные файлы к коммиту.
2. Diff наглядно показывает добавленные и удалённые строки рядом с исходной версией.
3. Граф истории и GitLens помогают связать изменение строки с коммитом и его автором.

## Что удобнее в терминале
Интерактивный rebase удобно запускать явно через git rebase -i HEAD~3: видна выбранная граница истории и список действий pick/squash.
