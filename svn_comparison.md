# Сравнение Git и SVN

## 1. Почему ветвление в Git дешёвое
Ветка Git - подвижная ссылка на коммит. Создание ветки не копирует все файлы и выполняется локально.
Формулировку о «дорогом» ветвлении SVN следует уточнить: SVN тоже использует дешёвое копирование (cheap copies), а не полное дублирование дерева. Ветвь представлена каталогом в центральном репозитории; для публикации и большинства операций с историей нужен доступ к серверу. Отличаются модель работы и зависимость от сервера, а не обязательное полное копирование данных.

## 2. Возможен ли коммит SVN без интернета
Коммит требует доступности репозитория. Если сервер удалённый и связи с ним нет, коммит невозможен: локальных коммитов, как в Git, нет. Интернет не обязателен при доступном сервере в локальной сети или репозитории file://.

## 3. Когда SVN может быть предпочтительнее
SVN может подходить существующему проекту с настроенными процессами, централизованным управлением и правами на отдельные каталоги. Блокировки файлов полезны при работе с двоичными ресурсами, которые трудно сливать. Миграция на Git не всегда оправдана затратами.
