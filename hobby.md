# Мой пет-проект

Идея: консольное приложение для учёта личных расходов.

Стек: Python 3, SQLite, pytest, Docker, GitHub Actions.

Цель: научиться хранить данные в SQLite, покрывать расчёты тестами и автоматически проверять изменения в CI.

Основные функции:
- Добавление расхода с датой и категорией.
- Просмотр суммы расходов за месяц.
- Экспорт записей в CSV.

## Первый этап
Реализовать добавление расхода и подсчёт общей суммы за месяц.
